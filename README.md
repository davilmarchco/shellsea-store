# SheLL Sea Beachwear

Site oficial da SheLL Sea Beachwear — biquínis artesanais feitos à mão em Niterói, com pingentes e pedras para personalizar o conjunto.

## Desenvolvimento

Requisitos: Node.js e npm ([instalar com nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
git clone <this-repository-url>
cd shellsea-store
npm i
npm run dev
```
